# Java e orientação a objetos — Sementes Tech

Atividades de Java realizadas no projeto Sementes Tech, conforme a descrição original do repositório. Os exemplos são organizados por aula e preservam a evolução do estudo.

## Mapa da árvore

- `src/aula_1`: exercícios iniciais, tipos, condicionais e laços.
- `src/aula_2` e `src/aula_3`: exemplos de cliente, conta e produtos de investimento.
- `src/aula_4`: exemplos com veículos, componentes e combustíveis.
- `src/aula_5`: arquivo de estudo de try/catch.
- `src/aula_6` e `src/aula_7`: exemplos de vetores, listas e usuários.

Em `src/aula_3/ContaCorrente.java`, a classe estende `Conta` e recebe um `Produto` na operação de investimento. É um exemplo didático de modelagem e herança, sem validação de cálculos financeiros ou uso bancário real.

## Ambiente e limites

O projeto contém configuração Eclipse: `.classpath` usa `src` como origem, `bin` como saída e um JRE genérico. A árvore não contém Maven/Gradle e a versão do JDK não está fixada nessa configuração. Escolha a classe da aula desejada e confira suas dependências antes de executar em uma IDE Java.
